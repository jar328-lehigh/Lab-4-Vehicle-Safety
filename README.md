# Lab-4-Vehicle-Safety

Marina Falzone & Jared Rabadam

This project models a safety interlock and warning system of a car, intended for a BASYS 3 FPGA Board. It accepts inputs from the board's switches and displays output on the board's LEDs.

To simulate, upload the two Verilog files and the constraint file to Vivado. For FPGA Implementation, run implementation and generate the bitstream and program the board. Match the board input to the testbench and test your cases.
